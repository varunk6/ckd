# CKD Predict — Chronic Kidney Disease Prediction System

CKD Predict is an end-to-end educational machine learning application that predicts the risk of Chronic Kidney Disease (CKD) based on clinical patient health parameters.

## Technology Stack

- **Frontend**: React 19, Vite, Tailwind CSS v4, Lucide React icons, React Router v7
- **Backend**: Python 3.14, FastAPI, Uvicorn, Pydantic v2, SQLite (`ckd_history.db`)
- **Machine Learning**: scikit-learn, Random Forest Classifier (`random_state=42`), pandas, NumPy, joblib

---

## Machine Learning Pipeline

1. **Dataset**: Legitimate UCI Chronic Kidney Disease dataset saved in `backend/data/kidney_disease.csv`.
2. **Preprocessing**: Missing value imputation (median for numeric, mode for categorical), feature scaling, and one-hot encoding.
3. **Model**: Trained Random Forest Classifier (`n_estimators=100`, `random_state=42`).
4. **Evaluation**: Exported to `backend/model/metrics.json` containing actual Accuracy, Precision, Recall, F1 Score, and Confusion Matrix.

## Setup & Running

### 1. Train the ML Model
```bash
python backend/model/train_model.py
```

### 2. Start Backend (FastAPI)
```bash
python -m uvicorn backend.main:app --port 8000 --reload
# Or double-click start-backend.bat
```
FastAPI Swagger documentation will be available at: `http://localhost:8000/docs`

### 3. Start Frontend (React + Vite)
```bash
npm run dev
# Or double-click start-frontend.bat
```
Web application will be accessible at: `http://localhost:5173`

## API Endpoints

- `GET /health`: Backend & ML model status check.
- `POST /predict`: Submit patient data & receive real ML prediction + probability %.
- `GET /model-info`: Actual trained model performance metrics.
- `GET /statistics`: DB statistics summary.
- `GET /predictions`: Historical prediction records from SQLite DB.
- `DELETE /predictions/{id}`: Delete a prediction record.
