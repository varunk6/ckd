Motivation & Vision

Problem & Objective

Addressing early detection challenges in renal healthcare through machine learning decision support

Clinical Problem
  • CKD progresses silently over months/years with subtle early symptoms.
  • Manual clinical evaluation across 24+ lab parameters is time-intensive.
  • Traditional models lack transparency ("black-box" decisions), causing clinician hesitancy.
Prototype Objective
  • Accept 24 patient clinical blood & urine parameters via modern UI.
  • Automate data scrubbing, median imputation, and StandardScaler normalization.
  • Compare 8 machine learning models using 5-Fold Stratified Cross-Validation.
  • Auto-select champion model and compute SHAP feature attributions.

1. Preprocessing & Scaling Implemented
  • Median Imputer for numerical columns
  • Mode Imputer for categorical columns
  • StandardScaler zero-mean scaling
  • OneHotEncoder categorical expansion
2. Feature Selection Implemented
  • Pearson Correlation Analysis
  • Chi-Square (χ²) Independence Test
  • Recursive Feature Elimination (RFE)
  • LASSO L1 & Mutual Information
3. Class Balancing & CV Implemented
  • SMOTE oversampling on training fold
  • SMOTETomek hybrid undersampling
  • Stratified 5-Fold Cross Validation
  • Zero data leakage architecture
